# 📌 E-Commerce Dataset Overview  

This dataset is a **synthetic e-commerce dataset** created using **Python** to simulate real-world business operations. It consists of multiple tables representing different aspects of an online retail business, including customer details, orders, products, payments, inventory, and shipping. This dataset can be used for various data analysis tasks such as customer behavior analysis, sales trends, inventory management, and operational efficiency.  

## 📂 Dataset Structure  

The dataset comprises the following **9 tables**:  

1. **Customers** - Contains details about customers such as their name, location, and unique ID.  
2. **Orders** - Stores information about each order, including the order date, customer ID, and order status.  
3. **Order Items** - Represents individual items purchased within an order, linking products to transactions.  
4. **Products** - Includes details about the products available for sale, such as product names, prices, and categories.  
5. **Categories** - Defines product categories for better classification.  
6. **Sellers** - Information about sellers listing products on the platform.  
7. **Payments** - Tracks payment transactions, including payment methods and statuses.  
8. **Inventory** - Maintains stock details for products, helping in inventory management.  
9. **Shipping** - Captures delivery-related details such as shipping dates, return statuses, and delivery times.

## 🔍 Key Analysis Performed  

This dataset enables several critical analyses that help in **business intelligence and decision-making**:  

### 📊 **Customer Analysis**  
- Identified unique customers who placed orders.  
- Determined the state with the highest number of customers.  
- Analyzed total orders placed by each customer.  
- Calculated the average number of orders per customer.  

### 💰 **Sales & Order Analysis**  
- Computed total revenue generated from all orders.  
- Determined the average order value (AOV).  
- Identified top-selling and least-performing products.  
- Analyzed monthly sales trends and found the highest revenue-generating month.  
- Examined total revenue per product category.  

### 📦 **Inventory Management**  
- Identified products with the lowest stock remaining.  
- Calculated the total stock value for each product.  
- Listed products that need urgent restocking.  

### 🛒 **Seller Performance**  
- Found the top sellers contributing the most revenue.  
- Computed the average product price for each seller.  

### 💳 **Payment & Refund Analysis**  
- Determined the most commonly used payment mode.  
- Analyzed the percentage of orders with failed payments.  

### 🚚 **Shipping & Delivery Analysis**  
- Computed the average delivery time for orders.  
- Calculated the percentage of orders that were returned.  
- Identified the most common order status.  

### 📈 **Profitability & Customer Value**  
- Determined the most profitable product category.  
- Identified customers contributing to the top 10% of revenue.  
- Analyzed product reorder rates.
